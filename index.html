Proposé gratuitement par Max Nicolet

1. Type de machine

Choisis le type de machine et donne-lui un nom. Ce nom apparaîtra dans le PDF.

PulvMalin vous accompagne dans la calibration de votre pulvérisateur. Cette application est en version "Work in progress". Les réglages proposés sont théoriques et doivent être vérifiés sur la machine.

2. Réglages & buses

Arbo / Tangentiel

Nombre total de buses (pair). Elles seront réparties moitié gauche, moitié droite.

Viti — modèle de répartition
Rampe désherbage — 1 rang

Nombre total de buses sur la rampe.

3. Mode pastille

Sans cocher, PULV MALIN choisit automatiquement la pastille la plus adaptée pour chaque sortie.

En mode forcé, les pastilles choisies sont imposées pour les groupes correspondants. La pression est calculée et signalée si hors plage.
